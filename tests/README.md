# 测试脚本目录

本目录包含AI4S平台的各种测试脚本，用于验证系统功能和排查问题。

## 脚本列表

### 1. 用户目录挂载测试
**文件**: `test-user-mount.sh`

**功能**: 测试用户目录挂载是否正常工作
- 检查环境变量配置
- 验证宿主机目录结构
- 检查Docker Compose挂载配置
- 验证管理后端容器内挂载点

**使用方法**:
```bash
./tests/test-user-mount.sh
```

### 2. 网站访问测试
**文件**: `test-website-access.sh`

**功能**: 测试网站访问是否正常
- 检查服务状态
- 验证端口监听
- 测试网站页面访问
- 检查API接口状态
- 验证静态资源访问

**使用方法**:
```bash
./tests/test-website-access.sh
```

## 运行所有测试

```bash
# 运行用户目录挂载测试
./tests/test-user-mount.sh

# 运行网站访问测试
./tests/test-website-access.sh
```

## 测试脚本特点

- ✅ **自动化检查**: 自动检测各种配置和状态
- ✅ **彩色输出**: 使用颜色区分不同类型的信息
- ✅ **详细报告**: 提供详细的测试结果和建议
- ✅ **错误处理**: 包含错误检测和故障排除建议

## 常见问题排查

### 用户目录挂载问题
如果用户目录挂载测试失败：
1. 检查环境变量是否正确设置
2. 验证宿主机目录权限
3. 确认Docker Compose配置
4. 重启管理后端服务

### 网站访问问题
如果网站访问测试失败：
1. 检查容器是否正常运行
2. 验证端口是否正确监听
3. 查看容器日志
4. 重启相关服务

## 添加新测试脚本

在添加新的测试脚本时，请遵循以下规范：

1. **命名规范**: 使用 `test-功能名称.sh` 格式
2. **权限设置**: 确保脚本有执行权限 (`chmod +x`)
3. **颜色输出**: 使用颜色定义来区分信息类型
4. **错误处理**: 包含适当的错误检测和处理
5. **文档说明**: 在README中说明脚本功能和使用方法

## 依赖要求

- Docker 和 Docker Compose
- curl (用于网络测试)
- netstat (用于端口检查)
- bash shell

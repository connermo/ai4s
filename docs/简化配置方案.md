# 简化配置方案

## 🎯 **配置简化目标**

将复杂的多路径配置简化为单一数据根目录配置，其他目录自动生成。

## 📋 **简化前后对比**

### **简化前（复杂配置）**
```bash
# 需要配置多个路径
USERS_DATA_PATH=/app/users
GROUPS_DATA_PATH=/app/groups
HOST_USERS_PATH=/root/work/ai4s/data/users
HOST_SHARED_RO_PATH=/root/work/ai4s/data/shared-ro
HOST_SHARED_RW_PATH=/root/work/ai4s/data/shared-rw
HOST_GROUPS_PATH=/root/work/ai4s/data/groups
```

### **简化后（单一配置）**
```bash
# 只需要配置一个数据根目录
DATA_ROOT=/root/work/ai4s/data
```

## 🔧 **实现方案**

### **1. Docker Compose配置**
```yaml
volumes:
  - "${DATA_ROOT:-./data}:/app/data"  # 单一挂载点
environment:
  - DATA_ROOT=${DATA_ROOT:-/root/work/ai4s/data}  # 单一环境变量
```

### **2. 自动生成的目录结构**
```
/app/data/
├── users/          # 用户数据目录
├── shared-ro/      # 共享只读目录
├── shared-rw/      # 共享读写目录
└── groups/         # 组数据目录
```

### **3. 后端代码自动处理**
```go
// 自动生成子目录路径
usersDataPath := "/app/data/users"
sharedRoPath := "/app/data/shared-ro"
sharedRwPath := "/app/data/shared-rw"

// 宿主机路径（基于DATA_ROOT）
hostUserDir := fmt.Sprintf("%s/users/%s", dataRoot, user.Username)
hostSharedPath := fmt.Sprintf("%s/shared-ro", dataRoot)
hostWorkspacePath := fmt.Sprintf("%s/shared-rw", dataRoot)
```

## 📁 **目录结构**

### **宿主机目录**
```
/root/work/ai4s/data/
├── users/          # 用户数据
├── shared-ro/      # 共享只读
├── shared-rw/      # 共享读写
└── groups/         # 组数据
```

### **容器内目录**
```
/app/data/
├── users/          # 用户数据
├── shared-ro/      # 共享只读
├── shared-rw/      # 共享读写
└── groups/         # 组数据
```

## 🛠️ **使用方式**

### **1. 新机器部署**
```bash
# 运行简化设置脚本
./scripts/setup-simple.sh
```

### **2. 手动配置**
```bash
# 设置数据根目录
export DATA_ROOT=/path/to/your/data

# 创建目录结构
mkdir -p $DATA_ROOT/{users,shared-ro,shared-rw,groups}
```

### **3. 验证配置**
```bash
# 运行测试脚本
./tests/test-simple-mount.sh
```

## ✅ **优势**

1. **配置简单** - 只需要设置一个DATA_ROOT路径
2. **自动生成** - 子目录自动创建和管理
3. **跨机器兼容** - 使用绝对路径，解决其他机器问题
4. **维护方便** - 减少配置项，降低出错概率
5. **扩展性好** - 新增目录只需在代码中添加

## 🔄 **迁移步骤**

1. **备份当前配置**
   ```bash
   cp .env .env.backup
   ```

2. **运行简化设置**
   ```bash
   ./scripts/setup-simple.sh
   ```

3. **重启服务**
   ```bash
   docker compose down && docker compose up -d
   ```

4. **验证配置**
   ```bash
   ./tests/test-simple-mount.sh
   ```

## 📝 **注意事项**

1. **数据迁移** - 如果已有数据，需要手动迁移到新目录结构
2. **权限设置** - shared-rw目录需要写权限（777）
3. **路径一致性** - 确保宿主机和容器内路径一致
4. **环境变量** - DATA_ROOT必须是绝对路径

# 统一默认配置方案

## 🎯 **配置统一目标**

删除所有容器内配置，采用统一的硬编码默认配置，进一步简化部署和维护。

## 📋 **配置简化对比**

### **简化前（多环境变量配置）**
```bash
# 需要配置多个环境变量
CONTAINER_HOME_PATH=/home
CONTAINER_SHARED_RO_PATH=/shared-ro
CONTAINER_SHARED_RW_PATH=/shared-rw
CONTAINER_GROUPS_PATH=/groups
USER_CONTAINER_IMAGE=connermo/ai4s-env:latest
```

### **简化后（统一默认配置）**
```bash
# 只需要配置一个数据根目录
DATA_ROOT=/root/work/ai4s/data
```

## 🔧 **实现方案**

### **1. Docker Compose配置**
```yaml
environment:
  - PORT=${PORT:-8080}
  - DB_DSN=${DB_DSN:-platform:platform123@tcp(mysql:3306)/gpu_platform?charset=utf8mb4&parseTime=True&loc=Local}
  - DEFAULT_PORT_PREFIX=${DEFAULT_PORT_PREFIX:-10000}
  - PORT_STEP=${PORT_STEP:-10}
  - DATA_ROOT=${DATA_ROOT:-/root/work/ai4s/data}
```

### **2. 后端代码硬编码默认值**
```go
// 使用统一的默认配置
containerHomePath := "/home"
containerSharedPath := "/shared-ro"
containerWorkspacePath := "/shared-rw"
containerGroupsPath := "/groups"

// 用户容器镜像
var userContainerImage = "connermo/ai4s-env:latest"
```

### **3. 自动生成的目录结构**
```
/app/data/
├── users/          # 用户数据目录
├── shared-ro/      # 共享只读目录
├── shared-rw/      # 共享读写目录
└── groups/         # 组数据目录
```

## 🛠️ **使用方式**

### **1. 新机器部署**
```bash
# 运行简化设置脚本
./scripts/setup-simple.sh
```

### **2. 手动配置**
```bash
# 只需要设置数据根目录
export DATA_ROOT=/path/to/your/data

# 创建目录结构
mkdir -p $DATA_ROOT/{users,shared-ro,shared-rw,groups}
```

### **3. 验证配置**
```bash
# 运行测试脚本
./tests/test-simple-mount.sh
```

## ✅ **优势**

1. **极简配置** - 只需要设置一个DATA_ROOT路径
2. **统一标准** - 所有路径都是硬编码的默认值
3. **零配置** - 容器内路径完全不需要配置
4. **跨机器兼容** - 使用绝对路径，解决其他机器问题
5. **维护简单** - 减少配置项，降低出错概率
6. **部署快速** - 新机器部署只需要几分钟

## 🔄 **迁移步骤**

1. **备份当前配置**
   ```bash
   cp .env .env.backup
   ```

2. **运行简化设置**
   ```bash
   ./scripts/setup-simple.sh
   ```

3. **重启服务**
   ```bash
   docker compose down && docker compose up -d
   ```

4. **验证配置**
   ```bash
   ./tests/test-simple-mount.sh
   ```

## 📝 **注意事项**

1. **数据迁移** - 如果已有数据，需要手动迁移到新目录结构
2. **权限设置** - shared-rw目录需要写权限（777）
3. **路径一致性** - 确保宿主机和容器内路径一致
4. **环境变量** - DATA_ROOT必须是绝对路径

## 🎉 **最终配置**

### **.env文件（极简配置）**
```bash
# 数据库配置
DB_DSN="platform:platform123@tcp(mysql:3306)/gpu_platform?charset=utf8mb4&parseTime=True&loc=Local"

# 服务端口
PORT=8080

# 用户端口配置
DEFAULT_PORT_PREFIX=10000
PORT_STEP=10

# 数据根目录配置（唯一需要配置的项）
DATA_ROOT=/root/work/ai4s/data
```

### **硬编码默认值**
- 用户容器镜像: `connermo/ai4s-env:latest`
- 容器内用户目录: `/home`
- 容器内共享只读: `/shared-ro`
- 容器内共享读写: `/shared-rw`
- 容器内组目录: `/groups`

- ✅ 自动目录生成和管理
- ✅ 跨机器兼容性

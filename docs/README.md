## 📋 **快速参考**

### **最终配置（推荐）**
```bash
# 只需要配置一个数据根目录
DATA_ROOT=/path/to/your/data
```

### **部署命令**
```bash
# 1. 复制配置文件
cp .env.example .env

# 2. 运行简化设置
./scripts/setup-simple.sh

# 3. 启动服务
docker compose up -d

# 4. 验证配置
./tests/test-simple-mount.sh
```

### **常用脚本**
- `./scripts/setup-simple.sh` - 简化环境设置
- `./tests/test-simple-mount.sh` - 挂载配置测试
- `./scripts/cleanup-unused-dirs.sh` - 清理无用目录
